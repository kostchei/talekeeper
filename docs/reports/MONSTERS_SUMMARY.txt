--------------------------------------------------------------------------------
XML STRUCTURE
--------------------------------------------------------------------------------

Each monster includes:
  - Basic Info (name, size, type, alignment)
  - Image Path (empty, ready for images)
  - Combat Stats (AC, HP, Initiative, Speed)
  - Ability Scores (all 6 with modifiers and saves)
  - Skills, Resistances, Vulnerabilities, Immunities
  - Senses and Languages
  - CR, XP, Proficiency Bonus
  - Traits (passive abilities)
  - Actions (including Multiattack)
  - Bonus Actions (if any)
  - Reactions (if any)
  - Legendary Actions (if any)

Attributes:
  - id="monster_id" - Unique identifier
  - validate_stats="true" - Enable database validation
  - source="SRD_CC_v5.2.1" - Data source

--------------------------------------------------------------------------------
CUSTOM MONSTERS
--------------------------------------------------------------------------------

To add custom/homebrew monsters:

<monster id="volcanic_drake" validate_stats="false" source="custom">
  <name>Volcanic Drake</name>
  <image_path>images/monsters/custom/volcanic_drake.png</image_path>
  <basic_info>
    <size>Large</size>
    <type>Dragon</type>
    <alignment>Chaotic Evil</alignment>
  </basic_info>
  <!-- rest of monster definition -->
</monster>

Set validate_stats="false" for custom monsters to skip database validation.

EXAMPLE USAGE IN PYTHON
--------------------------------------------------------------------------------

LOAD XML:
  import xml.etree.ElementTree as ET

  tree = ET.parse('database/seeds/monsters_complete.xml')
  root = tree.getroot()

  for monster in root.findall('monster'):
      name = monster.find('name').text
      cr = monster.find('cr').text
      print(f'{name} (CR {cr})')

LOAD FROM DATABASE:
  import sqlite3

  conn = sqlite3.connect('talekeeper.db')
  cursor = conn.cursor()

  cursor.execute('SELECT name, challenge_rating, hit_points FROM monsters WHERE challenge_rating = ?', ('10',))
  for name, cr, hp in cursor.fetchall():
      print(f'{name} (CR {cr}, HP {hp})')

DISPLAY IMAGE (PyQt6):
  from PyQt6.QtGui import QPixmap

  image_path = monster.find('image_path').text
  if image_path:
      pixmap = QPixmap(image_path)
      label.setPixmap(pixmap)

TROUBLESHOOTING

  SOLUTION: Check XML structure against template in monsters.xml

  SOLUTION: Verify image_path is correct and file exists

  SOLUTION: Use compare_monsters.py to identify differences
